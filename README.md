# 密码管理器（Password Manager）

一个运行在本地的桌面密码管理器，基于 Electron 开发。所有数据加密存储在本地，不依赖任何云服务。

## 功能特性

- **主密码解锁**：首次设置主密码，之后用它解锁保险库，主密码绝不落盘
- **条目管理**：分类保存网站、用户名、密码、网址、备注，支持搜索
- **密码生成器**：按长度与字符类型生成强密码，估算熵值强度
- **TOTP 两步验证**：支持 `otpauth://` 链接或 base32 密钥，实时显示动态验证码
- **自动锁定**：空闲超时自动锁定（可设置 1/5/15/30 分钟或关闭）
- **导入 / 导出**：CSV、JSON 明文格式
- **加密备份**：`.pmbackup` 加密备份，跨设备用相同主密码即可恢复

## 安全设计

- 加密算法：`AES-256-GCM`（带认证标签，可检测篡改）
- 密钥派生：主密码经 `scrypt`（N=16384, r=8, p=1）派生 32 字节密钥
- 解锁后的数据只驻留在主进程内存中，锁定即清空
- 渲染进程开启 `contextIsolation` / `sandbox`，关闭 `nodeIntegration`
- 复制到剪贴板的密码会在 30 秒后自动清除

## 技术栈

- [Electron](https://www.electronjs.org/) 33
- [electron-builder](https://www.electron.build/)（打包）
- 无其他运行时依赖（加密、TOTP、CSV 解析均基于 Node 内置 `crypto` / `fs` 实现）

## 安装与运行

### 直接使用安装包

双击运行 `dist7/密码管理器-Setup-1.0.6.exe`，安装完成后桌面会生成「密码管理器」快捷方式。

### 开发者运行

```bash
npm install      # 安装依赖
npm start        # 启动应用
```

### 打包

```bash
npm run build    # 生成 Windows 安装包到 dist/ 目录
```

## 使用说明

### 1. 首次创建主密码

首次运行会进入「创建主密码」界面：

1. 在「主密码」框输入密码（至少 4 位）
2. 在「确认主密码」框再次输入相同密码
3. 点击「创建保险库」或按回车

> 请务必牢记主密码。由于数据经主密码加密，**主密码丢失后无法找回数据**。

### 2. 解锁保险库

后续运行会进入「解锁保险库」界面，输入主密码即可解锁，右侧会显示你保存的条目列表。

### 3. 管理条目

- 点击「新建条目」添加网站/账号/密码等
- 点击左侧条目查看详情，可复制用户名、密码等字段
- 点击「编辑」修改，点击「删除」移除（不可恢复）

### 4. 密码生成器

点击「密码生成器」，设置长度（4–128）与字符类型（大写/小写/数字/符号），点击「重新生成」或「复制」。

### 5. TOTP 两步验证

编辑条目时，在「两步验证（TOTP）」中填写服务商提供的 `otpauth://` 链接或 base32 密钥。保存后，条目详情页会实时显示 6 位动态验证码与剩余秒数。

### 6. 自动锁定

点击「设置」，在「自动锁定」下拉框中选择空闲超时时间（关闭 / 1 / 5 / 15 / 30 分钟）。超时无操作会自动锁定，需重新输入主密码。

### 7. 导入 / 导出

「设置」面板提供：

- 导出 / 导入 CSV、JSON（明文格式，便于迁移到其他工具）
- 导出 / 恢复加密备份（`.pmbackup`，需输入主密码）

> 明文 CSV / JSON 导出后请妥善保管，避免泄露。

## 数据存储位置

保险库文件名为 `vault.pm`，保存在 Electron 的用户数据目录：

- Windows 打包版：`%APPDATA%\密码管理器\vault.pm`
- 开发运行：`%APPDATA%\password-manager\vault.pm`
